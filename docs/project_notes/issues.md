# Issues

Work log keyed by ticket / PR / dated entry. Useful when the project uses a ticket system; skip otherwise. Reverse-chronological — newest first.

This project doesn't use a ticket system today. The active work tracker is `data/todos.md` (read by the recap script) and the broader `~/projects/<project>/docs/plans/` collection (read by Claude when planning). Use this file only for entries that don't fit either of those — e.g. cross-cutting work logs, post-incident reviews, sprint retrospectives.

## Format

```
## YYYY-MM-DD — TICKET-ID or short title
- What was done.
- What's still open.
- Blockers / dependencies.
```
