## Runtime
- Default port: `8000` (overridable via `PORT` env var)
- Process manager / startup: cron `@reboot` runs `python run_server.py` from project venv (`~/projects/reels-digest-agent/.venv/bin/python`)
- Restart command: `pkill -f run_server.py && cd ~/projects/reels-digest-agent && nohup .venv/bin/python run_server.py > /tmp/fastapi.log 2>&1 &`
- Log location: `/tmp/fastapi.log` (default), `logs/` (digest + recap output)
- Database: SQLite WAL at `data/reels.db`
- Download dir: `data/downloads/` (audio temp, article zips under `data/downloads/articles/`)

## External dependencies
- Anthropic API — reel summarization (Sonnet 4.6 vision), article + reel planning, voice transcription via Whisper (local model)
- Notion API — `notion-client` 3.x, daily digest published as one page per day; uses `data_sources.query` (not deprecated `databases.query`)
- Telegram Bot API — `sendMessage` from `recap.py` (independent of MCP plugin's `getUpdates` polling, same token, no conflict)
- yt-dlp — Instagram media download (audio-only for reels, image carousels as-is)
- ffmpeg — keyframe extraction (3 evenly-spaced frames per video)
- Whisper — local transcription (model size via `WHISPER_MODEL`, default `base`)
- Playwright + Chromium — article fetching via `src/generic_article_fetcher.py` (Playwright ≥1.58 since 2026-05-06; the scrapling[fetchers] install pulled the upgrade and a fresh `playwright install chromium` was required)
- Scrapling — fast HTTP fetcher used as first tier in `src/scrapling_fetcher.py` for non-Medium URLs. `pip install scrapling[fetchers]` (pulls `curl_cffi`, `patchright`)

## Endpoints (FastAPI, bearer auth from `WEBHOOK_SECRET`)
- `POST /api/reel` — queue Instagram URL. Idempotent. Response action ∈ `{queued, requeued, already_pending, already_done}`.
- `POST /api/article` — synchronous article fetch. Returns `{title, author, image_count, zip_path}`. Zip path is absolute on this host.
- `POST /api/transcribe` — Whisper transcription. Body `{"file_path": "..."}`. Path-validated to `/tmp/`, project data dir, or `~/.claude/channels/telegram/inbox/`.
- `GET /api/status` — queue counts `{pending, done, error}`.

## Article fetcher benchmark (10-URL suite, 2026-05-06)
- Suite: `scripts/benchmark_urls.txt`. Mix of medium.com proper, medium publication subdomains, custom-domain Medium pubs, and 3 plain blogs.
- Run: `python -m scripts.benchmark_fetchers --fetcher playwright` (full suite) or `--fetcher scrapling --skip-medium` (Scrapling on non-Medium only).
- Per-fetch log: `data/fetch_log.jsonl`. Fields: `ts`, `url`, `host`, `fetcher` (`playwright` | `playwright+readability` | `scrapling` | `scrapling+stealth` | `scrapling+readability`), `fetch_duration_ms`, `body_chars`, `error`.
- **Plain non-Medium URLs (the win):** paulgraham.com 3561ms→673ms (5.3×), overreacted.io 25994ms→985ms (26×). Both well under the 1500-char/2s threshold from the plan.
- **Custom-domain Medium pubs:** Scrapling alone returns ~3KB stub; Playwright's canonical-medium.com retry returns ~50KB. Routed straight to Playwright.
- **Medium proper:** unchanged from baseline (8–17s). Cookie injection requires Playwright storage_state.
- Wiring threshold: `_SCRAPLING_MIN_CONTENT_CHARS = 1600` in `generic_article_fetcher.py` (1500-char body + ~100-char header).
